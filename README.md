# Do-it

Eigene, selbst gehostete Todo-App für eine kleine Gruppe:

- Aufgaben in normaler Sprache eingeben („Morgen 15 Uhr Zahnarzt anrufen #Gesundheit“), Datum, Projekt, Person und Erinnerung werden automatisch erkannt
- Erinnerungen als Push-Benachrichtigung auf Android, Desktop und iPad
- Offline-first mit Synchronisierung über den eigenen Server (Proxmox, Docker Compose, Reverse Proxy)
- Geteilte Projekte, Zuweisungen und rotierende Haushaltsaufgaben

Status: Planung. Architektur, Entscheidungen und Fahrplan stehen in [docs/BAUPLAN.md](docs/BAUPLAN.md).
